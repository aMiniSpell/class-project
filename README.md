<h>Description</h>
<p>Muller's Method to numerically solve for roots of a polynomial written in Python. 
Users must input valid polynomials, stopping criteria, and initial points to output an approximate root.</p>
<p> From my <a href="https://github.com/aMiniSpell/class-project-proposal" target="_blank">class project proposal</a>
I incorporated the basics of for loops, while loops, and user inputs with restrictions and error messages.
I ensured invalid inputs display proper errors i.e. syntax errors, invalid characters, and domain restrictions
using functions not taught in class. I also delivered on displaying both real and complex solutions.</p>
